How to Use

        

          
Translate: Opens a separate screen. Use Chrome’s Translate page option, then select Back to Editor to keep the translated text.

          
Split into Lines: Adds a line break after each sentence and dialogue. The result becomes your current text.

          
Make It Colloquial: Applies colloquial Persian rules to the current text. Translate first if needed. You can run this before or after splitting into lines.

          
Split into Chunks: Divides the current text using the character limit in Settings. Each chunk has its number and a copy button; the last copied chunk stays green.

          
These actions are separate. Use them in any order.
